# Security

Valet handles passwords, one-time codes and signed-in sessions, so security reports are welcome
even at this pre-alpha stage.

Please report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/njdancer/valet/security/advisories/new), not
in a public issue. Include what you found, how to reproduce it, and what an attacker gains.

The design and its threat model are in [docs/security-model.md](docs/security-model.md). Nothing
is released yet, so there are no supported versions; fixes land on `main`.
