# Component inventory for the wireframes

Every wireframe is drawn from one small kit (`wireframes/kit.js`, `wireframes/kit.css`). This table is
the contract with the design system: each wireframe element names the component it needs, the states
the wireframes use, and the rule from the research it carries. The design-system thread maps its
`@valet/ui` components onto this list and flags gaps.

## @valet/ui names (from the design-system thread, 2026-11-11)

Badge (tones success/warning/danger/info/neutral), RiskBadge (read/write/irreversible, shape plus
colour), InboxItem (alias NeedsYouItem, with missed state), ObjectLink (icon and hover card), Value
(with copy), HealthLine, DescriptionList, Table + RowLink or List + ListRow, EmptyState, Segmented,
ConfirmDialog (`dialog()`), SheetContent (`sheet()`), SplitView with Inspector (`.split`),
Toolbar/TitleBar with SplitButton (Pause / Lock down), Deadline, FilterChip, Timeline, TrayPanel
(menu bar popover), ConfirmationPanel, CanReach, ShellStatus (paused and locked-down strip). Button
`disabledReason` makes a disabled button focusable with a tooltip and accessible description.
