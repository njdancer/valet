Information architecture

Six places in the sidebar. Activity holds two real tabs, Calls and Audit log, each with its own address and shortcut. The window opens on Needs you when anything waits, otherwise on Sites. Full rationale in docs/ux/information-architecture.md.

What the persona tests decided

QuestionDecisionWhy
NavigationSix places (IA-A)Won for the keyboard user, the agent and the away owner; never worse than "unsure" for anyone. "Access" (IA-C) confused four personas; seven places (IA-B) was too many for two.
Calls vs audit logTwo real tabs under Activity, own address and shortcut eachThe power user and the adapter author wanted each one keystroke away.
Home pageNeeds you's empty state shows the system statusThe installer and the security reviewer wanted a Home summary; everyone else wanted a Needs you place they can name.
Status vs actionBadges never click; a labelled button sits beside themAll seven personas. A chevron pill (E1b) "still looks like every other pill".
LabelsNeeds you · Sites · Activity · Connections · Secrets · Settings"Sites" won 6 to 1; "Secrets" 4 to 2, with "Passwords and one-time codes" as its subtitle and search synonym.

Navigation map

Every object links to every object it mentions, both ways. Notifications and the menu bar open the item itself, never a list.
