How to read these

Each group is one journey from docs/ux/agent-run/journeys.md, plus a group of approval cards (J4) drawn for every kind in approval-cards.md. Within a group: the happy path first, then failures, then dead ends. Every frame shows the world in story.md: Thursday 19 November 2026, 7:40 pm; Nick at a café with his iPhone; his MacBook Pro at home. Notes say when a frame shows another moment.

Phone frames use native iOS structures (tab bar, navigation bar, inset grouped lists, page sheets, alerts, the system Face ID sheet) so the iOS app can map each to a SwiftUI component. Mac frames use the v3 kit and only draw what changes; anything not drawn is as in the v3 wireframes.

The iPhone app

Tab bar: Needs you (badge) · Activity · Sites · Agents · Valet

Needs you     the same inbox and titles as the Mac · a card opens as a page sheet · Pause and Lock down in its menu
Activity      Changes (first: what agents changed, who approved, Undo) · Calls (redacted steps)
Sites         health, tools with remote on/off per agent, versions (written by / approved on), drafts (read only)
Agents        capabilities (Use tools · See Valet · Ask for changes), remote tools, waiting requests, Revoke · Add an agent
Valet         the Mac's status · Pause Valet · Lock down · Devices · Secrets (read, remove) · Notifications · Unpair
