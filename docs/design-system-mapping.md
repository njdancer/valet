# Design system mapping: wireframes v1 → @valet/ui

This maps every frame of the UX thread's wireframes (v1, branch `claude/project-thread-12eeic`,
`docs/ux/wireframes/frames/*.js`, 73 frames in 10 groups) onto the components exported by
`packages/ui/src/index.ts`. Frame ids are stable and are the keys of this document; frame names are
the wireframe titles. Read it with `docs/design-system.md` (catalogue, layout and interaction rules)
and `docs/ux/information-architecture.md` (routes, vocabulary).

Conventions:

- Component names and props are real exports and real props unless marked **Gn** (a gap, see
  [Gaps](#gaps)) or **Mn** (a mismatch, see [Mismatches](#mismatches)).
- "Shell" means the control window: `AppShell` with `Sidebar` (`SidebarGroup` of `NavItem`, a
  "Sites" `SidebarGroup` of `NavItem` with `SiteAvatar size="xs"` and `trailing={<StatusDot label>}`,
  `SidebarFooter`), `TitleBar` (`onBack`, `onForward`, `onSearch`, `actions={<SplitButton>Pause
  Valet</SplitButton>}` with `DropdownMenuItem` "Lock down…"), and the page as `Page` > `PageHeader`
  \+ `PageBody` (+ `ActionBar`). Every shell frame uses this unless noted.
- Kit to library, used throughout: `K.badge` → `Badge` (ok→`success`, warn→`warning`,
  bad→`danger`, idle→`neutral`, info→`info`, read/write/secret→`RiskBadge`/`SecretBadge`);
  `K.link` → `ObjectLink`; `K.value` → `Value copy` or `HashChip`; `K.countdown` → `DeadlineChip`;
  `K.health` → `HealthLine`; `K.banner` → `Banner`; `K.card` → `Card` (`CardHeader`, `CardTitle`,
  `CardContent`); `K.kv` → `DescriptionList`; `K.inbox` → `InboxItem`; `K.empty` → `EmptyState`;
  `K.toast` → `toast()`; `K.seg` → `Segmented`; `K.toggle` → `Switch`; `K.radio` → `RadioOption`;
  `K.dot` → `StatusDot` (info→`accent`); `.sticky-foot` → `ActionBar`; `sheet()` → `SheetContent`;
  `dialog()` → `ConfirmDialog`; `.split`/`.insp` → `SplitView` inspector.

Counts: 73 frames mapped (Needs you 3, Sites 18, Activity 9, Connections 6, Secrets 3, Settings 5,
Menu bar 6, Own windows 7, Setup 10, Everywhere 6). 43 gaps, 30 mismatches.
