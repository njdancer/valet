# Design system mapping: wireframes v2 → @valet/ui

This maps every frame of the UX thread's wireframes v2 (branch `claude/project-thread-12eeic`,
`docs/ux/wireframes/frames/*.js`, PR #59) onto the components exported by `packages/ui/src/index.ts`.
Every v2 frame draws one moment, set out in `docs/ux/wireframes/story.md`: Saturday 7 Nov 2026,
9:48 pm, four things waiting (confirm 7F2A, approve a connection, login check 9A71, review
Woolworths 0.4.0). Frame ids are stable and are the keys of this document; frame names are the
wireframe titles. Read it with `docs/design-system.md` (catalogue, layout and interaction rules) and
`docs/ux/information-architecture.md` (routes, vocabulary).

Conventions:

- Component names and props are real exports and real props unless marked **Gn** (a gap, see
  [Gaps](#gaps)) or **Mn** (a mismatch, see [Mismatches](#mismatches)). Gaps are numbered in
  priority order; mismatches keep their v1 numbers.
- "Shell" means the control window: `AppShell` with `Sidebar` (224 px, no `collapsible`; `SidebarGroup`
  of `NavItem`, a "Sites" `SidebarGroup` of `NavItem` with `SiteAvatar size="xs"` and
  `trailing={<StatusDot label>}`, `SidebarFooter`), `TitleBar` (`onBack`, `onForward`, `onSearch`
  "Search sites, calls, apps", `actions={<SplitButton>Pause Valet</SplitButton>}` with
  `DropdownMenuItem` "Lock down…"), `ShellStatus` under the titlebar when paused or locked, and the page
  as `Page` > `PageHeader` + `PageBody` (+ `ActionBar`). Every shell frame uses this unless noted.
- Site header (every Woolworths page): `PageHeader` (`breadcrumb`, `leading={<SiteAvatar size="lg">}`,
  title, status **G9**, `description`, `actions` = `Button` "Open my trolley…" + `ObjectLink` "All
  calls" + `DropdownMenu` on `IconButton label="More actions for Woolworths"`, children = `NavTabs`
  Overview / Tools / Permissions / Versions **G39**).
- Kit to library, used throughout: `K.badge` → `Badge` (ok→`success`, warn→`warning`, bad→`danger`,
  idle→`neutral`, info→`info`; read/write/secret→`RiskBadge`/`SecretBadge`); `K.link` → `ObjectLink`;
  `K.value` → `Value copy` or `HashChip`; `K.countdown` → `DeadlineChip`; `K.health` → `HealthLine`;
  `K.banner` → `Banner`; `K.card` → `Card` (`CardHeader`, `CardTitle`, `CardContent`); `K.kv` →
  `DescriptionList`; `K.inbox` → `InboxItem`; `K.empty` → `EmptyState`; `K.toast` → `toast()`;
  `K.seg` → `Segmented`; `K.toggle` → `Switch`; `K.radio` → `RadioOption`; `K.check` → **G19**
  `CheckboxOption`; `K.dot` → `StatusDot` (info→`accent`); `.sticky-foot` → `ActionBar`; `sheet()` →
  `SheetContent`; `dialog()` → `ConfirmDialog`; `.split`/`.insp` → `SplitView` inspector.

Counts: 87 frames mapped (Needs you 4, Sites 21, Activity 10, Connections 7, Secrets 4, Settings 5,
Menu bar 7, Own windows 10, Setup 12, Everywhere 7). 47 gaps (P0 8, P1 24, P2 15). 22 open
mismatches (18 from v1, 4 new); 12 v1 mismatches resolved in full and 2 in part.

Priority means how much the MVP path needs the gap closed. The MVP path is: install and set up,
approve the Woolworths adapter, grant the login, then Claude places an order that asks for a
confirmation (and may hit a login check). P0: needed on that path. P1: needed soon after, or on a
page the path passes through. P2: polish or later features.
