Calls are attributed to the token that made them. What a client says its name is appears in grey and proves nothing. Revoking a token stops only that client.
Add to Claude Codestdio bridge, bundled with the app 
claude mcp add siteadapter -- \
  /Applications/siteadapter.app/Contents/Resources/bin/siteadapter-mcp
Other clients that only speak stdio:
{ "mcpServers": { "siteadapter": { "command":
  "/Applications/siteadapter.app/Contents/Resources/bin/siteadapter-mcp"
} } }
The bridge reads Claude Code's token from your Keychain, so it never sits in a config file.

Not covered by the security model yet. Needs your call: whether v0 has it at all, which tools a remote caller may use (proposed: read only), and a separate token for each remote device.
TailscalecloudflaredRelay later
  1. Install Tailscale on this Mac and the device you'll call from, signed in to the same tailnet.
  2. Serve the endpoint on your tailnet only: 
    tailscale serve --bg 47821
  3. Point the remote client at https://macbook.tail1c2d.ts.net/mcp with a token issued for that device.
Anyone on the tailnet with that token can call whatever it's scoped to. Irreversible tools still wait for you on this Mac. Don't use tailscale funnel; it makes the endpoint public.
